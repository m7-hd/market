## 📋 نظرة عامة | Overview

**Mhmd Market** هو نظام إدارة سوبر ماركت شامل ومتكامل، مصمم بأحدث التقنيات ليكون تحفة فنية في عالم أنظمة الإدارة. يجمع النظام بين الجمال البصري الفاخر والقوة الوظيفية الكاملة، مع دعم كامل للغة العربية (RTL) والإنجليزية (LTR)، ووضع داكن أنيق، وتطبيق ويب تقدمي قابل للتثبيت على جميع الأجهزة.

> **Mhmd Market** is a complete, professional supermarket management system built with cutting-edge technologies. It combines luxurious visual aesthetics with full functional power, supporting Arabic (RTL) and English (LTR), elegant dark mode, and a Progressive Web App installable on all devices.

## 🚀 التشغيل السريع | Quick Start

### المتطلبات | Prerequisites

- **Node.js** 18.17+ (الإصدار 20 موصى به | v20 recommended)
- **npm** أو | or **pnpm** أو | or **yarn**

### الخطوات | Steps

```bash
# 1. استنساخ المستودع | Clone the repository
git clone https://github.com/YOUR_USERNAME/mhmd-market.git
cd mhmd-market

# 2. تثبيت الحزم | Install dependencies
npm install

# 3. نسخ ملف المتغيرات | Copy env file
cp .env.example .env.local

# 4. تشغيل وضع التطوير | Run development server
npm run dev
```

افتح المتصفح على | Open your browser at: **http://localhost:3000**

### بناء للإنتاج | Production Build

```bash
npm run build
npm start
```

> 💡 **بدون إعداد Supabase**، يعمل النظام في **الوضع التجريبي (Demo Mode)** باستخدام بيانات محلية مخزنة في المتصفح. لا تحتاج أي إعداد إضافي للتجربة!
>
> 💡 **Without Supabase setup**, the app runs in **Demo Mode** using local browser-stored seed data. No backend needed to try it out!

## ☁️ النشر | Deployment (GitHub + Vercel + Supabase)

### الخطوة 1: إنشاء مشروع Supabase | Step 1: Create Supabase Project

1. اذهب إلى | Go to [supabase.com](https://supabase.com) وأنشئ حسابًا | and create an account
2. أنشئ مشروعًا جديدًا | Create a new project
3. انتظر حتى يكتمل الإعداد | Wait for provisioning to complete
4. اذهب إلى | Go to **Project Settings → API**
5. انسخ | Copy:
   - `Project URL` → `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### الخطوة 2: تشغيل هجرة قاعدة البيانات | Step 2: Run Database Migration

1. في Supabase Dashboard، اذهب إلى | In Supabase Dashboard, go to **SQL Editor**
2. اضغط | Click **New query**
3. افتح ملف | Open the file `supabase/migration.sql`
4. انسخ كامل المحتوى والصقه في محرر SQL | Copy all content and paste into the SQL editor
5. اضغط | Click **Run** (▶)
6. تأكد من إنشاء جميع الجداول بنجاح | Verify all tables created successfully

> تشمل الهجرة: الجداول، الفهارس، سياسات RLS، التريجرز، وبيانات أولية | The migration includes: tables, indexes, RLS policies, triggers, and seed data

### الخطوة 3: رفع المشروع إلى GitHub | Step 3: Push to GitHub

```bash
# تهيئة Git | Initialize Git
cd mhmd-market
git init
git add .
git commit -m "feat: Mhmd Market - complete supermarket management system"

# إنشاء مستودع على GitHub ثم | Create a repo on GitHub, then:
git remote add origin https://github.com/YOUR_USERNAME/mhmd-market.git
git branch -M main
git push -u origin main
```

> ⚠️ تأكد من أن ملف `.env.local` **غير** مرفوع (موجود في `.gitignore`)
> ⚠️ Ensure `.env.local` is **NOT** pushed (it's in `.gitignore`)

### الخطوة 4: النشر على Vercel | Step 4: Deploy to Vercel

1. اذهب إلى | Go to [vercel.com](https://vercel.com) وسجّل الدخول بحساب GitHub | and sign in with GitHub
2. اضغط | Click **Add New → Project**
3. استورد مستودع | Import the repo `mhmd-market`
4. في | In **Environment Variables**, أضف | add:

   | Key | Value |
   |-----|-------|
   | `NEXT_PUBLIC_SUPABASE_URL` | `https://your-project.supabase.co` |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `your-anon-key` |
   | `NEXT_PUBLIC_APP_NAME` | `Mhmd Market` (اختياري | optional) |

5. اضغط | Click **Deploy** 🎉
6. انتظر دقائق حتى يكتمل البناء | Wait a few minutes for build to complete
7. تطبيقك جاهز على | Your app is live at: `https://mhmd-market.vercel.app`

### الخطوة 5 (اختياري): إعداد مصادقة Supabase | Step 5 (Optional): Configure Supabase Auth

1. في Supabase Dashboard → **Authentication → Providers**
2. فعّل | Enable **Email/Phone**
3. أضف عنوان Vercel إلى | Add your Vercel URL to **Site URL** and **Redirect URLs**
4. أنشئ أول مستخدم مدير عبر | Create the first admin user via **Authentication → Users → Add user**

## 🌐 الوضع التجريبي | Demo Mode

عند عدم توفير بيانات Supabase (`NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`)، يعمل النظام تلقائيًا في **الوضع التجريبي**:

- ✅ جميع الميزات تعمل بالكامل
- ✅ البيانات مخزنة محليًا في المتصفح (localStorage)
- ✅ بيانات أولية جاهزة (منتجات، عملاء، موردين، فواتير)
- ✅ لا حاجة لأي إعداد خادم

When Supabase credentials are not provided, the system automatically runs in **Demo Mode**:

- ✅ All features fully functional
- ✅ Data stored locally in the browser (localStorage)
- ✅ Pre-seeded sample data (products, customers, suppliers, invoices)
- ✅ No server setup required
